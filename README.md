# westbound.app

The public website for Westbound, an iPhone app for Colorado's I-70 mountain corridor: home page, privacy policy and support page. Plain HTML served by GitHub Pages at https://westbound.app.

- When the policy in `privacy/index.html` changes, update its "Effective" date.
- The font (Alfa Slab One, SIL Open Font License) is self-hosted in `assets/` so pages make no third-party requests.
- `CNAME` holds the custom domain. Don't delete it.
